# Viral OS MVP User Stories

## Research
- As an operator, I want to enter a topic so that Viral OS can research related public signals.
- As an operator, I want to see source priority so that I know which sources are closest to viral behavior.
- As an operator, I want extracted hooks and viral elements so that I can understand why a draft was generated.

## Draft Generation
- As an operator, I want Threads-only draft posts so that I can prepare content for Threads without cross-platform noise.
- As an operator, I want drafts to be grounded in observations so that posts feel human and specific.
- As an operator, I want score breakdowns so that I can compare drafts quickly.

## Approval
- As an operator, I want to approve a draft before publishing so that nothing posts automatically.
- As an operator, I want to reject a draft so that weak posts do not enter the queue.
- As an operator, I want to edit a draft before approval so that the final post matches my voice.

## Scheduling
- As an operator, I want to schedule an approved draft so that it publishes later.
- As an operator, I want cron to publish due approved posts so that I do not need to manually watch the clock.
- As an operator, I want failed jobs to be visible so that I can fix issues.

## Threads Publishing
- As an operator, I want only approved posts to publish to Threads so that every public action is controlled.
- As an operator, I want the Threads post ID saved so that I can trace published content.
