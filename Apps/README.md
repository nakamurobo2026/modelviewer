# 材料価格管理 PWA

## iPhoneに入れる流れ
1. このフォルダを GitHub Pages / Netlify / Vercel / 自分のサーバー にアップロード
2. iPhoneのSafariでURLを開く
3. 共有ボタン
4. 「ホーム画面に追加」
5. アプリのように起動できます

## 機能
- 材料価格の登録
- 商品名検索
- 価格推移グラフ
- CSV書き出し
- CSV読み込み
- ホーム画面追加対応
- オフライン起動対応

## 注意
iPhoneはZIPをそのままインストールできません。
必ず一度Web上に公開して、Safariから「ホーム画面に追加」してください。
