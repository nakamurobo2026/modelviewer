# 材料価格管理PWA Full

## 全乗せ内容
- カメラ撮影
- 画像選択
- OCR解析（Tesseract.js / 初回はネット必要）
- OCR結果の手修正
- 明細抽出
- 抽出明細の確認・編集
- 一括登録
- 登録済み納品書データ入り
- 検索・集計・価格推移グラフ
- CSV読み書き
- PWA対応

## 注意
OCRはブラウザ内で動く無料版なので、完璧ではありません。
実務では「OCR → 確認画面で手直し → 登録」の運用が安全です。
